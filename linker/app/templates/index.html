Host storage

Lists external drives plus an "Internal drive" option under your home folder - using the internal drive is completely fine, it's just a normal folder there instead of an external disk. (macOS's own named system/boot volume specifically is left out: unlike a regular folder or a real external drive, Docker Desktop doesn't reliably bind-mount that one - a folder can report as created there without ever landing on the real disk.) Click "Use this" to create movies/tv/downloads folders, point .env at them, and recreate Sonarr, Radarr, Plex and qBittorrent with the new paths - all automatic.

Downloads cleanup

Once Sonarr/Radarr import a finished download into movies/tv, the original stays behind in DOWNLOADS_PATH (from .env) too - so it exists on disk twice. This job periodically empties just the downloads folder to reclaim that duplicated space.

Warning: this stops seeding. qBittorrent keeps listing a torrent as seeding after this runs, but once its file is deleted here it can no longer serve it to other peers - qBittorrent has no way to detect the deletion and won't pause or remove the torrent itself.
